# Architecture diagram style

All three diagrams use a Carbon background: near-black neutral graphite
(`#141619`), matte and smooth, with off-white handwriting, pale cyan lines,
and green/yellow/red/white finding symbols.

For future image edits, use the current PNG as the reference. Preserve wording,
layout, boxes, connectors and foreground colors; change only the requested detail.
The current images were edited with built-in image_gen.

The combined diagram is exported at 4608 × 3072 from a 1536 × 1024 native image;
resampling adds no detail. EVM and Solana are 1536 × 1024.
README and the HTML viewer reference the stable `*-architecture-dark.png` paths.
