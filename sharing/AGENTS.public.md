# Project guidance

- Canonical skills live in the three folders under `skills/`. Keep them together.
- Codex EVM registration is the relative `.agents/skills/crypto-evm-token-due-diligence`
  symlink. Do not create a second EVM copy or Personal registration.
- The Claude EVM copy has host adaptations described in its `CLAUDE-CODE-PORT.md`.
  Edit canonical first, mirror shared changes, and retain the documented differences.
- Preserve evidence, exact identity, pins, routing, unknowns and finite session budgets.
- Read the current user's provider policy in `HANDOFF.md` before any provider attempt.
  Keep credentials outside this repository. Configuration alone grants no paid access.
- Research is read-only: no real-key signing or transaction broadcast.
- Use implement, review, improve for changes; run the relevant README unittest suites.
- Keep run output under ignored `research/` or `runs/`; never substitute prior token
  evidence for a fresh investigation.
